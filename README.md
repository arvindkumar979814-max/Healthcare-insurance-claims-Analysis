# Healthcare-insurance-claims-Analysis

## Project Overview

This project analyzes healthcare insurance claims using
Python and Microsoft Power BI.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI
- DAX

## EDA Performed

- Missing Value Analysis
- Descriptive Statistics
- Distribution Analysis
- Correlation Analysis
- Outlier Detection
- Categorical Analysis
- Relationship Analysis

## Power BI Dashboard

The dashboard includes:

- Total Patients
- Total Claims
- Average Claim
- Highest Claim
- Average Claim by Region
- Smoker vs Non-Smoker Analysis
- Diabetic vs Non-Diabetic Analysis
- Gender Distribution
- Age vs Claim
- BMI vs Claim
- Blood Pressure vs Claim
- Children vs Average Claim
- Interactive Slicers

Data Cleaning | EDA | Data Visualization |
Power BI | DAX | Python | Pandas
